# Game Vision — 2Dドットアクションゲーム

> 状態: 初稿（v0.1） / 更新日: 2026-10-15  
> この文書は「最終的に届けたい体験」を定義する。現在実装する内容は [`prototype-spec.md`](prototype-spec.md) を参照する。

## 1. ひとことで言うと

**片手で軽快に操作でき、敵の動きとギミックを学習するほど上達を実感できる、戦闘重視の2Dドットアクションゲーム。**

メトロイドヴァニアのように能力獲得と探索による発見を含むが、初作品では広大なマップを目指さず、戦闘の完成度を優先する。

## 2. 目指すプレイ体験

1. **操作は簡単、判断は奥深い。** 左手だけで基本操作を完結させ、複雑なコマンドや長いコンボを求めない。
2. **敵を観察して勝つ。** 予備動作、攻撃範囲、発生順、攻撃後の隙を読み、位置取り・ジャンプ・ダッシュ・攻撃のタイミングを判断する。
3. **失敗から知識が残る。** 初見で全てを見切る必要はない。繰り返し挑戦する中で、失敗の理由やギミックの法則を理解できるようにする。
4. **正攻法と技術的な別解を両立する。** ギミックを理解して安全地帯へ移動するのが安定解でも、短い無敵ダッシュを正確に合わせることで突破できる場面も作る。
5. **学んだ知識が後で役立つ。** 序盤で覚えた予兆や法則が、後半のボスで演出を変えたり、ほかのギミックと組み合わされたりして再登場する。
6. **新しい能力で同じ操作に新しい意味が生まれる。** ボス撃破を節目に、空中ダッシュや通常攻撃による弾の反射などを解放し、戦闘と探索の両方を変化させる。

## 3. ゲームデザインの柱

### 3.1 軽快なアクションと、攻撃するリスク

- 左右移動・ジャンプ・ダッシュ・単発の通常攻撃が基本。
- 空中でも移動方向を調整し、攻撃できる。
- 攻撃には短い硬直があり、その一部ではダッシュでキャンセルできない。
- ダッシュの短い無敵時間は重要な回避手段だが、持続攻撃や位置取りを必要とするギミックを万能には解決できない。
- スタミナ制は導入しない。

### 3.2 敵とボスで異なる手応え

- 小型の雑魚敵は1対1なら攻撃で制圧できてもよい。複数体の配置で位置取りや優先順位を考えさせる。
- 一部の雑魚敵は攻撃モーションにスーパーアーマー（怯み耐性）を持ち、攻撃連打だけで勝ち続けることを防ぐ。
- ボスは通常攻撃では基本的に怯まない。特定のギミック成功時に限り、短い中断・ブレイクが起きる場合がある。
- 攻撃命中の手応え（音・エフェクトなど）と、敵の行動を中断する「怯み」は別の概念として扱う。

### 3.3 推測し、覚え、組み合わせるボス戦

- 初期のボスは平坦なフィールドを主体にし、基本の読み合いを学ばせる。
- 後半は高低差やすり抜け足場を取り入れ、既存操作を組み合わせる難易度を上げる。
- 同じギミックをそのまま繰り返すのではなく、「共通の法則」を別の演出や組み合わせで再利用する。
- ボスを怯ませるギミックは強力すぎる必勝手段にせず、リスクを取って狙える選択肢にする。

### 3.4 控えめでも意味のある探索

- 初作品では一本道寄りの進行を基本に、寄り道や後から訪れられる場所を少数配置する。
- 能力は基本的にボス撃破で獲得する方向。必ずしも広大な探索の報酬にしない。
- 能力獲得で以前は届かなかった場所に行ける、といったメトロイドヴァニアらしい変化は残す。

## 4. 想定するプレイループ

```text
小さなエリアを進む
  ↓
雑魚敵や地形で基本アクションを使う
  ↓
ボスの予兆・ギミックを観察する
  ↓
失敗と再挑戦を通して理解を深める
  ↓
ボス撃破 → 既存アクションが拡張される
  ↓
新能力を使って次のエリア・戦闘に挑む
```

## 5. 制作上の方針

- **エンジン:** Godot 4系を採用し、GDScriptを中心に学ぶ。
- **実装方法:** Codexに小さな単位で実装を任せ、コード・Godotの概念・操作感を毎段階レビューする。
- **初期グラフィック:** 四角形などの仮素材を使用。戦闘の手触りが固まってからドット絵とアニメーションを本制作する。
- **ドット絵制作:** NovelAIはキャラクターのイメージ検討などへの活用候補。アニメーションのフレーム整合性を踏まえ、制作手法は未決定。
- **スコープ管理:** 先に「ボス1体との戦闘が楽しい」状態を目指し、その後に探索・能力解放を広げる。

## 6. 初作品の規模（未確定の目安）

以下は**合意済みの開発目標ではなく、規模感を検討するための仮案**。

- プレイ時間: 10〜20分程度
- ボス: 2体程度（ただし最初のマイルストーンは1体）
- 雑魚敵: 2〜3種類程度
- エリア: 3〜5部屋程度
- 能力解放: 1種類程度
- 探索: 基本は一本道で、少数の寄り道や再訪要素

品質・制作負荷を見て縮小／変更してよい。公開プラットフォーム、正式タイトル、世界観、ストーリー、画面解像度は未決定。

## 7. 今回は中心に置かないもの

- 多数の武器・装備ビルドやステータス育成
- スタミナ管理
- 複雑な攻撃コンボ
- 大規模な非線形マップや大量の隠し要素
- 最初から完成版のドット絵を量産すること

これらを将来にわたって禁止するわけではなく、初作品の中心的価値にはしない、という判断。
