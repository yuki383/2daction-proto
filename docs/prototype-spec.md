# Prototype Specification — Phase 1: 左右移動とジャンプ

> 状態: 実装依頼用の初稿（v0.1） / 更新日: 2026-10-15  
> **今回の実装はこの文書に記載した範囲のみ。** ゲーム全体の構想は [`game-vision.md`](game-vision.md) / [`game-design.md`](game-design.md) にあるが、先行実装はしない。

## 1. このフェーズの目的

- Godotの**シーン、ノード、GDScript、物理更新**を実際に動くプロジェクトで理解する。
- プレイヤーの左右移動・通常ジャンプ・着地・空中での方向転換を成立させる。
- 後続の操作感調整へ進むための、最小限のテストステージを作る。

**このフェーズでは戦闘の面白さや完成した操作感の評価までは行わない。**

## 2. 採用技術

- ゲームエンジン: **Godot 4系**（リポジトリ内で使用する具体的なバージョンはプロジェクト開始時に明記する）
- スクリプト: **GDScript**
- 物理キャラクター: `CharacterBody2D`
- 入力: Godotの**Input Map**。コード内にキー定数を直接散らさない。
- グラフィック: 色付き四角形などの**仮表示**。アセットの生成・調達は不要。

## 3. 実装する機能

| 機能 | 必須動作 |
| --- | --- |
| 左移動 | `A`を押している間、左へ動く |
| 右移動 | `D`を押している間、右へ動く |
| 停止 | 左右入力を離すと横方向の移動が止まる（Phase 1は即停止でよい） |
| ジャンプ | 地面に立っている状態で`Space`を押すと上方向へジャンプする |
| 重力・着地 | ジャンプ後に落下し、床で止まる |
| 空中制御 | ジャンプ中も`A/D`で左右方向へ移動・方向転換できる |
| ジャンプ制限 | 地面にいないときは再ジャンプできない（ダブルジャンプなし） |
| パラメータ調整 | 移動速度・ジャンプ初速・重力をInspectorから変更できる |
| テストステージ | 地面とプレイヤーを配置した小さなシーンを起動できる |

### 3.1 推奨ノード構成

```text
TestLevel (Node2D)
├── Player (インスタンス化したPlayerシーン)
└── Ground (StaticBody2D)
    ├── CollisionShape2D
    └── Polygon2D              # 仮表示

Player (CharacterBody2D)       # 別シーン
├── CollisionShape2D
└── Polygon2D                  # 仮表示
```

これは初期案。不要なノードを増やさず、同等に理解しやすい構造なら変更可能。シーン名やファイル名はわかりやすい英語名にする。

### 3.2 移動の実装方針

- `_physics_process(delta)`で物理移動を更新する。
- `is_on_floor()`で接地状態を確認する。
- `velocity`に重力・ジャンプ初速・水平速度を反映し、`move_and_slide()`で衝突を考慮して移動する。
- 左右入力には`Input.get_axis("move_left", "move_right")`等、Input Mapのアクション名を利用する。
- `Space`の押下判定には`Input.is_action_just_pressed("jump")`等を利用する。
- Godotの2D座標では下向きが正であるため、ジャンプ初速は通常負の数になる。

### 3.3 調整値の仮設定

Inspectorで調整可能な`@export`変数として用意する。下記は**動作確認用の仮値**で、ゲームデザイン上の決定ではない。

| パラメータ | 仮値 | 単位の考え方 |
| --- | ---: | --- |
| 横移動速度 | `220` | pixel / 秒 |
| ジャンプ初速 | `-360` | pixel / 秒（上向き） |
| 重力加速度 | `1000` | pixel / 秒² |

表示解像度、床の幅、キャラクターの大きさはテストが成立する範囲で暫定設定する。将来のピクセルアート寸法として固定しない。

## 4. 今回は実装しないもの

- ダッシュ、無敵時間、空中ダッシュ
- 通常攻撃、敵、ダメージ、当たり判定（床との衝突以外）、ボス、ギミック
- 長押しによる可変ジャンプ、コヨーテタイム、ジャンプバッファ
- 加速・減速、細かな空中制御パラメータ、複雑な移動状態管理
- すり抜け足場と`S + Space`（**ゲームの基本操作として採用済みだが、今回の実装対象外**）
- アニメーション、ドット絵、サウンド、UI、セーブ、探索マップ

今後の拡張を見越した大規模な状態マシンや独自フレームワークも不要。

## 5. 完了条件（手動チェック）

- [ ] Godotのエディタでプロジェクトを開き、テストステージを起動できる。
- [ ] `A/D`で左右移動し、キーを離すと停止する。
- [ ] 接地中に`Space`を押すとジャンプできる。
- [ ] 空中で左右を切り替えても移動できる。
- [ ] 空中で`Space`を連打しても再ジャンプしない。
- [ ] プレイヤーが地面をすり抜けず、着地後に再びジャンプできる。
- [ ] Inspectorから仮パラメータを変更すると挙動が変わる。
- [ ] 予期しないエラーが出ていない（実行環境にGodotがない場合は未検証と明記）。

## 6. Codexが実装後に説明すること

1. 追加・変更したファイル一覧。
2. シーンツリーと各ノードの責務。
3. `CharacterBody2D`、`CollisionShape2D`、`StaticBody2D`、Input Mapの役割。
4. `_physics_process(delta)`、`velocity`、`is_on_floor()`、`move_and_slide()`がどのように連動するか。
5. Godotエディタでの起動手順と、上記完了条件の確認方法。
6. 実際に動作確認したこと／確認できなかったこと。

## 7. 次の段階

Phase 1完了後に左右の加減速やジャンプの高さなどの**操作感調整**に進む。その後にダッシュ・攻撃・敵・ボスを小さな単位で加える。具体的な順序は [`development-plan.md`](development-plan.md) を参照する。
